## 我为什么愿意留着，却不拿它当主力

我对备用机场的要求，和主力不一样。主力要考虑每天用起来是否省心，备用则要先看自己一年能用上多少次。一个月只打开几回，却一直按主力的预算付费，未必划算。

赔钱机场吸引我的就是这部分需求。对地区没有太多要求，能找到合适的节点就行；任务也不赶时间，下载慢一点可以等等。这种用法下，没必要为了偶尔几次使用，把第二份订阅也买得很贵。

它真正的卖点很清晰：

- 价格极低（1.5 元/100G 起）
- 有 0.1x 和 0.01x 低倍率节点，下载特别划算
- 流量给得大方，还有不限时流量包
- 设备限制宽松，主流客户端都支持

不过，便宜备用不等于应急保障。如果你的要求是主力一出问题，它就必须立刻顶上，连工作都不能中断，那已经是另一种购买标准了。我会把赔钱机场当成手里多一个选择，不把重要任务的退路全押在它身上。

## 晚高峰能跑多快，要连同慢节点一起看

下面这张晚高峰测速表（环境为辽宁移动、1Gbps、单线程测试），记录了新加坡 2 的平均速度是 **12.42 MB/s**，最高速度 **18.07 MB/s**；新加坡 4 平均 **11.85 MB/s**。日本东京 04 那条标注 0.1 倍率的节点，平均也有 **7.13 MB/s**。只看这些节点，确实有承担普通下载任务的速度。

但完整图里，部分香港节点只有 KB/s 级别，还有一些节点当次没有跑出有效结果。同一份订阅里的差距相当明显，不能拿新加坡的最高速度代表所有地区，更不能把四月的一次测速当成现在每晚的表现。

网上很多用户也反馈同样的情况：能跑的节点速度够用，甚至 4K 都能看，但节点质量参差不齐，需要自己筛。尤其是只认某一个地区、不愿意换节点的人，光看流量价格很容易选错。

所以我觉得，这张图最有用的地方不是证明“这么便宜也能跑多快”，而是提醒你买完要筛一遍。先找到在自己宽带上能用的几条，再决定要不要继续买。

## 套餐怎么选，先想清楚多久用一次

| 你的用法                           | 我会怎么选                                                   |
| ---------------------------------- | ------------------------------------------------------------ |
| 第一次买，还不确定本地节点好不好用 | 直接选最低月付档（1.5 元 100G），先跑几天常用节点，确认速度和稳定性后再决定要不要加流量 |

| 每月都有娱乐或下载需求             | 按实际用量选月付档，重点用 0.1x / 0.01x 低倍率节点跑下载，流量会更划算 |
| 每天用来工作，不能接受中断         | 不建议按这篇的备用思路选，优先把预算放在更稳定的主力线路上   |

准备拿来下载，还要在付款前确认**每日用量限制**（官方是套餐总流量的 10%），以及低倍率节点如何扣流量。总流量多，不代表能集中在一天用完；节点名称里写着低倍率，也不等于可以不受限制地一直跑。用 0.01 倍率节点下载，实际可跑的量会大很多，这是它真正的性价比所在。

具体价格和在售套餐，付款前看一眼购买页就好。低频用户先买小额，下载用户先弄明白规则，比一开始追求最低的每 GB 单价更实际。

用作备用，也别导入以后就一直不管。隔段时间更新订阅、试一下常用节点，至少真正想用时，知道自己手里还有哪些选择。

用了一年，我对赔钱机场的推荐范围还是很明确。**已经有主力、想便宜添一个备用，或者使用频率低、愿意花点时间挑节点，可以考虑；想靠一份超低价订阅把工作和日常全部包下来，我不建议。**

它的核心卖点就是“便宜 + 低倍率下载 + 当备用够用”。先花小钱试出适合自己的节点，再决定要不要留下，这样买更符合它的定位。
